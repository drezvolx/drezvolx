<h2><b>05 / PRINCIPLES</b></h2>

<table>
  <tr>
    <td width="34%" valign="top">
      <b>HOW I APPROACH<br>WRITING CODE.</b>
    </td>
    <td width="66%" valign="top">
      <h3><b>Simplicity</b></h3>
      <p>Write less, mean more. Avoid unnecessary complexity.</p>

      <h3><b>Idiomatic Style</b></h3>
      <p>Write code that feels natural to the language. Follow established conventions and use language features as intended.</p>

      <h3><b>Standard First</b></h3>
      <p>Prefer the standard library and built-in solutions before adding another dependency.</p>

      <h3><b>Readability</b></h3>
      <p>Readable beats clever. Code should be easier to understand than it is to explain.</p>

      <h3><b>Consistency</b></h3>
      <p>Keep patterns consistent. Avoid introducing a new approach without a good reason.</p>
    </td>
  </tr>
</table>
